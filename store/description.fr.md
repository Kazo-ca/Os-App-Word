# Kazo Word

Un traitement de texte pour Kazo OS, construit sur [WordCraft](https://github.com/storytold/wordcraft).

En cours de développement : cette première version affiche WordCraft dans une fenêtre Kazo OS.
L'ouverture et l'enregistrement des fichiers Kazo OS arrivent dans les versions suivantes.

Ce texte est affiché sur la fiche de l'app dans le Kazo OS Store.
